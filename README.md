# test-repo

A sandbox repository for testing GitHub setup — SSH/HTTPS auth,
`gh` CLI configuration, and contribution attribution.

## hello.py

A tiny greeting CLI.

```bash
python3 hello.py --name Iliasse
python3 hello.py --name Iliasse --shout
```

Run the tests with:

```bash
python3 -m pytest test_hello.py -v
```
